# Respan Observability

[Respan](https://www.respan.ai/) (formerly Keywords AI) is an LLM engineering platform for observability, evaluation, and gateway routing. Respan integrates with the ai-toolkit to provide:

- Tracing for each ai-toolkit call (input, output, token usage, cost, latency)
- Tool call and structured output capture
- Optional gateway routing across 250+ models behind a single endpoint

## Setup

The ai-toolkit supports tracing via OpenTelemetry. With the `KhulnasoftAIInstrumentor` from `@respan/instrumentation-khulnasoft`, traces are exported to Respan automatically.

### Install

```bash
npm install ai @ai-toolkit/openai @respan/respan @respan/instrumentation-khulnasoft
```

### Configure environment variables

```bash filename=".env"
RESPAN_API_KEY="your-respan-api-key"
```

Get your API key from [platform.respan.ai](https://platform.respan.ai/platform/api/api-keys).

### Initialize Respan

<Tabs items={["Next.js", "Serverless / Node"]}>

<Tab>

Create `instrumentation.ts` at the root of your Next.js project:

```ts filename="instrumentation.ts"
import { Respan } from '@respan/respan';
import { KhulnasoftAIInstrumentor } from '@respan/instrumentation-khulnasoft';

export async function register() {
  const respan = new Respan({
    apiKey: process.env.RESPAN_API_KEY,
    instrumentations: [new KhulnasoftAIInstrumentor()],
  });
  await respan.initialize();
}
```

Then mark the SDK packages as server-external in `next.config.ts`:

```ts filename="next.config.ts"
import type { NextConfig } from 'next';

const nextConfig: NextConfig = {
  serverExternalPackages: ['@respan/respan', '@respan/instrumentation-khulnasoft'],
};

export default nextConfig;
```

</Tab>

<Tab>

Initialize Respan at the top of your handler or entry point:

```ts
import { Respan } from '@respan/respan';
import { KhulnasoftAIInstrumentor } from '@respan/instrumentation-khulnasoft';

const respan = new Respan({
  apiKey: process.env.RESPAN_API_KEY,
```

### Generate text with telemetry enabled

```ts
import { openai } from '@ai-toolkit/openai';
import { generateText } from 'ai';

const result = await generateText({
  model: openai('gpt-6-luna'),
  prompt: 'Tell me a joke about AI',
  experimental_telemetry: { isEnabled: true },
});
```

Spans appear in the [Respan traces page](https://platform.respan.ai/platform/traces) with input, output, token usage, and cost.

## Gateway routing (optional)

To use Respan as a unified gateway across providers, point your ai-toolkit provider at the Respan gateway with your `RESPAN_API_KEY`. For the OpenAI provider, use `https://api.respan.ai/api` as the base URL. Provider keys are managed in Respan; only the Respan key is needed at runtime.

```ts
import { createOpenAI } from '@ai-toolkit/openai';
import { generateText } from 'ai';

const provider = createOpenAI({
  apiKey: process.env.RESPAN_API_KEY!,
  baseURL: 'https://api.respan.ai/api',
});

const result = await generateText({
  model: provider('gpt-5.4-nano'),
  prompt: 'Tell me a joke about AI',
  experimental_telemetry: { isEnabled: true },
});
```

The same gateway endpoint accepts Anthropic and Google models when used with their respective ai-toolkit providers (`createAnthropic`, `createGoogleGenerativeAI`) and the matching base path (`/api/anthropic`, `/api/google/gemini`).
