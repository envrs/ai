# ai-toolkit Harnesses

ai-toolkit harness adapters connect `HarnessAgent` to established agent runtimes.
They are separate from model providers, but they expose ai-toolkit-compatible stream
and response primitives.

## Usage

All harness adapters are used with `HarnessAgent`:

```ts
import { HarnessAgent } from '@ai-toolkit/harness/agent';
import { codex } from '@ai-toolkit/harness-codex';
import { createVercelNetworkSandboxSession } from '@ai-toolkit/sandbox-khulnasoft';

const agent = new HarnessAgent({
  harness: codex,
  model: 'gpt-5.6-luna',
});

const sandboxSession = await createVercelNetworkSandboxSession({
  runtime: 'node24',
  ports: [4000],
  template: await agent.getSandboxTemplate(),
});
const session = await agent.createSession({ sandboxSession });
try {
  console.log(
    (await agent.generate({ session, prompt: 'Inspect this project.' })).text,
  );
} finally {
  await session.destroy();
  await sandboxSession.destroy();
}
```

Read the [Harnesses](/docs/ai-toolkit-harnesses) documentation for sessions,
tools, UI, and terminal usage.
