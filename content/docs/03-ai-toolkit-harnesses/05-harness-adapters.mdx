# Harness Adapters

Harness adapters connect `HarnessAgent` to a specific agent runtime. They are
the harness equivalent of ai-toolkit model providers: each adapter wraps one runtime
and normalizes its sessions, stream events, tools, usage, lifecycle state, and
configuration into the harness contract.

## ai-toolkit Harness Adapters

The ai-toolkit includes the following harness adapters:

- [Claude Code](/providers/ai-toolkit-harnesses/claude-code) (`@ai-toolkit/harness-claude-code`)
