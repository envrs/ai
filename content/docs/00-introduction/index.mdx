# ai-toolkit

The ai-toolkit is the TypeScript toolkit designed to help developers build AI-powered applications and agents with React, Next.js, Vue, Svelte, Node.js, and more.

## Why use the ai-toolkit?

Integrating large language models (LLMs) into applications is complicated and heavily dependent on the specific model provider you use.

The ai-toolkit standardizes integrating artificial intelligence (AI) models across [supported providers](/docs/foundations/providers-and-models). This enables developers to focus on building great AI applications, not waste time on technical details.

The ai-toolkit also includes a [harness abstraction](/docs/ai-toolkit-harnesses) for using
established agent harnesses such as Claude Code, Codex, and Pi through
`HarnessAgent`. Harnesses are decoupled from model providers, but use compatible
stream and response primitives so ai-toolkit UI and agent surfaces can consume them
in the same way.

The ai-toolkit has these primary surfaces:

- **[ai-toolkit Core](/docs/ai-toolkit-core):** A unified API for generating text, structured objects, tool calls, and building agents with LLMs.
- **[ai-toolkit UI](/docs/ai-toolkit-ui):** A set of framework-agnostic hooks for quickly building chat and generative user interfaces.
- **[ai-toolkit Harnesses](/docs/ai-toolkit-harnesses):** A uniform API for running established agent harnesses with `HarnessAgent`.

## `llms.txt` (for Cursor, Windsurf, Copilot, Claude etc.)

You can access the entire ai-toolkit documentation in Markdown format at [ai-toolkit.dev/llms.txt](/llms.txt). This can be used to ask any LLM (assuming it has a big enough context window) questions about the ai-toolkit based on the most up-to-date documentation.

### Example Usage

For instance, to prompt an LLM with questions about the ai-toolkit:

1. Copy the documentation contents from [ai-toolkit.dev/llms.txt](/llms.txt)
2. Use the following prompt format:

```prompt
Documentation:
{paste documentation here}
---
Based on the above documentation, answer the following:
{your question}
```
