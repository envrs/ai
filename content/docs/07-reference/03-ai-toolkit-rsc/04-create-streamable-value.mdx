# `createStreamableValue`

<Note type="warning">
  ai-toolkit RSC is currently experimental. We recommend using [ai-toolkit
  UI](/docs/ai-toolkit-ui/overview) for production. For guidance on migrating from
  RSC to UI, see our [migration guide](/docs/ai-toolkit-rsc/migrating-to-ui).
</Note>

Create a stream that sends values from the server to the client. The value can be any serializable data.
