# ai-toolkit Errors

The ai-toolkit exposes typed errors so applications can handle expected failure
modes without matching error message strings.

## Importing Errors

The application package is named `ai`, not `@ai-toolkit/ai`. It re-exports common
provider-level errors from `@ai-toolkit/provider` together with the higher-level
errors raised by ai-toolkit Core:

```typescript
import { APICallError, NoObjectGeneratedError } from 'ai';
```

Provider implementations that depend directly on `@ai-toolkit/provider` can import
its provider-level errors from that package instead:

```typescript
import { APICallError, InvalidResponseDataError } from '@ai-toolkit/provider';
```

## Migrating to Typed Error Handling

Replace message matching or an unconditionally generic `catch` block with the
most specific static `isInstance` guard available. Check `AIToolkitError` last when
you need a fallback for any ai-toolkit error:

```typescript
import { AIToolkitError, APICallError, generateText } from 'ai';

try {
  await generateText({
    model,
    prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  });
} catch (error) {
  if (APICallError.isInstance(error)) {
    console.error('Provider request failed:', error.statusCode);
    return;
  }

  if (AIToolkitError.isInstance(error)) {
    console.error('ai-toolkit error:', error.name);
    return;
  }

  throw error;
}
```

Prefer `ErrorClass.isInstance(error)` over `error instanceof ErrorClass` when
the class provides it. The static guard also works when multiple ai-toolkit package
versions are loaded.

## Common Failure Modes

| Failure mode                                                                           | Error to check                                                                                                                                                                                                                                                                              |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A provider request fails because of a network error or non-success response            | [`APICallError`](/docs/reference/ai-toolkit-errors/ai-api-call-error)                                                                                                                                                                                                                           |
| Automatic retries are exhausted                                                        | [`RetryError`](/docs/reference/ai-toolkit-errors/ai-retry-error)                                                                                                                                                                                                                                |
| A provider reports an error after a response stream has started                        | [`StreamProviderError`](/docs/reference/ai-toolkit-errors/ai-stream-provider-error)                                                                                                                                                                                                             |
| A structured output cannot be parsed or validated                                      | [`NoObjectGeneratedError`](/docs/reference/ai-toolkit-errors/ai-no-object-generated-error); inspect its `cause` for [`JSONParseError`](/docs/reference/ai-toolkit-errors/ai-json-parse-error) or [`TypeValidationError`](/docs/reference/ai-toolkit-errors/ai-type-validation-error)                    |
| A generation call returns no usable output                                             | [`NoOutputGeneratedError`](/docs/reference/ai-toolkit-errors/ai-no-output-generated-error) or the modality-specific `No*GeneratedError`                                                                                                                                                         |
| A model calls a missing tool or supplies invalid tool input                            | [`NoSuchToolError`](/docs/reference/ai-toolkit-errors/ai-no-such-tool-error) or [`InvalidToolInputError`](/docs/reference/ai-toolkit-errors/ai-invalid-tool-input-error)                                                                                                                            |
| Tool-call repair fails                                                                 | [`ToolCallRepairError`](/docs/reference/ai-toolkit-errors/ai-tool-call-repair-error)                                                                                                                                                                                                            |
| A response violates an enforced `toolChoice`                                           | [`ToolChoiceViolationError`](/docs/reference/ai-toolkit-errors/ai-tool-choice-violation-error)                                                                                                                                                                                                  |
| Message history contains unresolved tool calls or invalid approvals                    | [`MissingToolResultsError`](/docs/troubleshooting/missing-tool-results-error), [`InvalidToolApprovalError`](/docs/reference/ai-toolkit-errors/ai-invalid-tool-approval-error), or [`InvalidToolApprovalSignatureError`](/docs/reference/ai-toolkit-errors/ai-invalid-tool-approval-signature-error) |
| A provider or model cannot be resolved                                                 | [`NoSuchProviderError`](/docs/reference/ai-toolkit-errors/ai-no-such-provider-error), [`NoSuchModelError`](/docs/reference/ai-toolkit-errors/ai-no-such-model-error), or [`NoSuchProviderReferenceError`](/docs/reference/ai-toolkit-errors/ai-no-such-provider-reference-error)                        |
| A provider response is empty, malformed, or invalid                                    | [`EmptyResponseBodyError`](/docs/reference/ai-toolkit-errors/ai-empty-response-body-error), [`JSONParseError`](/docs/reference/ai-toolkit-errors/ai-json-parse-error), or [`InvalidResponseDataError`](/docs/reference/ai-toolkit-errors/ai-invalid-response-data-error)                                |
| The requested model or provider does not support a capability or specification version | [`UnsupportedFunctionalityError`](/docs/reference/ai-toolkit-errors/ai-unsupported-functionality-error) or [`UnsupportedModelVersionError`](/docs/troubleshooting/unsupported-model-version)                                                                                                    |
| UI messages cannot be converted or a UI message stream is invalid                      | [`MessageConversionError`](/docs/reference/ai-toolkit-errors/ai-message-conversion-error) or [`UIMessageStreamError`](/docs/reference/ai-toolkit-errors/ai-ui-message-stream-error)                                                                                                                 |
