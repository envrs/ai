# ai-toolkit UI

[ai-toolkit UI](/docs/ai-toolkit-ui) is designed to help you build interactive chat, completion, and assistant applications with ease.
It is a framework-agnostic toolkit, streamlining the integration of advanced AI functionalities into your applications.

ai-toolkit UI contains the following hooks:

## UI Framework Support

ai-toolkit UI supports the following frameworks: [React](https://react.dev/), [Svelte](https://svelte.dev/), [Vue.js](https://vuejs.org/),
[Angular](https://angular.dev/), and [SolidJS](https://www.solidjs.com/).

Here is a comparison of the supported functions across these frameworks:

|                                                                 | [useChat](/docs/reference/ai-toolkit-ui/use-chat) | [useCompletion](/docs/reference/ai-toolkit-ui/use-completion) | [useObject](/docs/reference/ai-toolkit-ui/use-object) | [MCP Apps](/docs/ai-toolkit-core/mcp-apps) |
| --------------------------------------------------------------- | --------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------- | -------------------------------------- |
| React `@ai-toolkit/react`                                           | <Check />                                     | <Check />                                                 | <Check />                                         | <Check />                              |
| Vue.js `@ai-toolkit/vue`                                            | <Check /> Chat                                | <Check />                                                 | <Check />                                         | <Cross />                              |
| Svelte `@ai-toolkit/svelte`                                         | <Check /> Chat                                | <Check /> Completion                                      | <Check /> StructuredObject                        | <Cross />                              |
| Angular `@ai-toolkit/angular`                                       | <Check /> Chat                                | <Check /> Completion                                      | <Check /> StructuredObject                        | <Cross />                              |
| [SolidJS](https://github.com/kodehort/ai-toolkit-solid) (community) | <Check />                                     | <Check />                                                 | <Check />                                         | <Cross />                              |
